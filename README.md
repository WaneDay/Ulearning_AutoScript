# 优学院自动舒服插件DGUT喵
一个用于优学院（youxueyuan）/ u学院平台的浏览器插件（仅测试了edge），支持自动播放视频、自动答题、自动翻页等功能

# 「优学院好舒服啊」安装教程

> 插件以 zip 形式发布在 GitHub Releases。本教程面向最终用户。

## 一、下载

1. 打开 GitHub 仓库，进入 **Releases（发行版）** 页面（仓库页右侧的 `Releases` 链接）。
2. 找到最新版本，下载里面的 **zip 压缩包**（文件名如 `优学院好舒服呀-v1.0.0.zip`）。
3. **解压** 该 zip 到本地任意位置（如 `D:\优学院好舒服呀`）。
   - 解压后文件夹里应能看到 `manifest.json` 等文件。

## 二、安装到 Edge

1. 打开 Microsoft Edge 浏览器。
2. 地址栏输入 `edge://extensions` 回车，进入扩展管理页。
3. 打开左下角 **开发人员模式** 开关。
4. 点击左上角 **加载解压缩的扩展**，选择刚才解压出来的**那个文件夹**（里面有 `manifest.json` 的那一层）。

5. 安装成功后，插件出现在扩展列表中，名称显示为 **优学院好舒服啊**。
<img width="1035" height="228" alt="3f79cf7f6978137fae19c604cf22c4bc" src="https://github.com/user-attachments/assets/5b6da6f4-9d18-4573-b459-a2c897dd2ccf" />

> 注意：`edge://extensions` 里**手动加载的扩展**在浏览器重启后仍会保留；但删除浏览器配置会失效，需要重新加载。

## 三、使用

1. 打开「优学院」课程页面，右上角出现可拖动的 **悬浮球**。
2. 点击悬浮球打开设置面板，可设置：
   - 自动翻页、播放视频
   - 自动静音
   - 自动调整播放速率（滑动条，范围 0.25 ~ 15）
   - 自动作答（显示答案、选择题、判断题、填空简答题）
3. 修改后点击 **保存设置并刷新脚本** 生效。
4. 面板顶部可切换 **浅色 / 深色 / 跟随系统** 主题。

## 四、更新

- 到 GitHub Releases 下载新版本 zip，解压后按「二、安装到 Edge」重新加载即可（可先删除旧版本）。
- 之前保存的设置一般会自动保留（存在浏览器本地）。

## 五、卸载

- `edge://extensions` → 找到 **优学院好舒服啊** → 点击 **删除**。
- 卸载不影响你的课程账号数据。

## 六、常见问题

| 问题 | 解决办法 |
| --- | --- |
| 没有「加载解压缩的扩展」按钮 | 确认左下角 **开发人员模式** 已开启 |
| 选文件夹后没反应 | 确认选中解压后包含 `manifest.json` 的那一层文件夹 |
| 没有悬浮球 | 刷新一次优学院课程页面 |
| 设置不生效 | 重新点击悬浮球上的「保存设置并刷新脚本」 |
